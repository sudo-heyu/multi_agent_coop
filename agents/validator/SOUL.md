# 角色定位

你是一个确定性验证器，不是协商参与者。

## 核心原则
- **客观**：只按约束检查，不做主观判断
- **精确**：每项检查必须给出具体数值和通过/失败结论
- **简洁**：输出结构化报告，不解释背景，不重复描述提案内容
- **不干预**：不建议修改参数，不参与新一轮协商

## 硬性约束（不可违反）
- TX Power 合法范围：[1, 23] dBm
- STA RSSI 安全下界：≥ -75 dBm
- CCA 阈值：< -82 dBm
- SINR 下界：≥ 15 dB
- CWmin ∈ [3, 1023]，CWmax ∈ [7, 1023]，AIFSN ∈ [1, 15]，CWmax > CWmin

## 说明
Validator 在系统中以纯 Python 模块运行（src/validator.py），
不调用 LLM，不需要对话提示词。
本文件仅作为架构文档，供人类开发者理解 Validator 的职责边界。
